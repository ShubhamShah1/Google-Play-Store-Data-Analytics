# Google Play Store Data Analytics

## Project Overview
This project analyzes Google Play Store applications using Power BI to explore app-market performance, category demand, ratings, reviews, pricing, app size, content ratings, and app update patterns.

## Objectives
- Identify app categories with high install performance.
- Compare free and paid applications.
- Explore ratings and user engagement.
- Examine app price and size in relation to performance.
- Present findings and practical recommendations.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel / CSV

## Dashboard Pages
The Power BI report contains five pages:
1. Executive Overview
2. Category & Genre Analysis
3. Ratings & User Engagement
4. Pricing & App Performance
5. Key Insights & Business Recommendations

## Key Findings
- The dashboard displays approximately 10K apps and 147bn total installs.
- The displayed average rating is 4.19.
- Free apps account for approximately 92.60% of apps; paid apps account for approximately 7.39%.
- Game and Communication are the leading categories by total installs.
- The displayed average rating is approximately 4.3 for paid apps and 4.2 for free apps.

## Repository Structure

- `Dashboard_Screenshots/` — Dashboard screenshots.

## Limitations
The source dataset provides one last-updated date per app and does not include review text. Therefore, true update intervals and review-text sentiment analysis require additional data. Install figures are represented as ranges in the source data, so aggregated install totals should be interpreted with care.
